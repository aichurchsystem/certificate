# 증명서 발급 앱 (독립 사이트)

대한예수교장로회(백석) 서울강동노회 증명서를 만들어 **인쇄 · PDF · 이미지(PNG)** 로 받는 설치형 웹앱(PWA)입니다.
주소: https://aichurchsystem.github.io/certificate/
저장소: https://github.com/aichurchsystem/certificate (main 브랜치 루트, GitHub Pages)

운동일지 앱(https://aichurchsystem.github.io/Church/)과 홈 화면 아이콘이 섞이지 않도록 **따로 떼어 낸 사이트**입니다. 매니페스트 `id`는 `/certificate/`, 서비스워커 캐시는 `certificate-standalone-v1`이며, 아이콘은 적갈색(#8B1D24) 바탕에 크림색 서류로 그려 운동일지(검정+금색)와 구분됩니다.

## 무엇을 할 수 있나
- 표지(시작) 화면: 앱을 열면 노회 머리글(흰 백석 로고 + `대한예수교장로회(백석) 서울강동노회`)과 큰 `증명서 발급`, 하늘색 `발급하기` 버튼이 있는 남색 표지가 먼저 뜹니다. 표지에서는 상단바·탭바를 감추고, `교인 명단 관리`로 관리자 화면의 사람 명단까지 바로 갑니다. 발급 화면 맨 위 `← 표지로`를 누르면 돌아옵니다. 표지 스타일은 `assets/app.css` 맨 아래 `cv-` 블록에 모여 있고, 인쇄물에는 표지가 끼지 않습니다.
- 관리자 탭: 지면 머리글·서명부(노회장·서기)·직인·안내문·7종 문구·항목 이름을 고치고 기본값으로 되돌리기, 사람·교회 명단 관리(사진 포함), 설정 JSON 내보내기/가져오기
- 증명서 종류 일곱 가지: 재직증명서 · 소속증명서 · 교회 개척확인증명서 · 교회 설립증명서 · 노회 참석 확인서 · 노회비 납부증명서 · 목사 안수 증명서
- 이름을 고르거나 이름·직분을 입력하면 `data/people.json`(및 기기 저장 명단)에서 직분·생년월일·교회명·교회 주소·대표자·기도처 시작일·설립일을 채웁니다. 명단에 사진이 있으면 지면 오른쪽 위에 3×4 증명사진으로 함께 인쇄됩니다.
- 기본 직인 3종(노회장 인·서기 인·노회 사각 인)이 기본으로 찍히고, 관리자에서 바꾸거나 지울 수 있습니다.
- 발급일·증명서 번호(`노회(증) 제YY-NNNNN호`)·Internet No. 자동 생성(고칠 수 있음).
- 발신처(기본 서울강동노회)·수신처(그때그때 입력, 비우면 인쇄되지 않음).
- 발급 이력(종류·이름·수신처로 찾기, 월별 보기, CSV 내려받기, 눌러서 다시 출력).
- A4 한 장 인쇄, 홈 화면에 설치, 오프라인에서도 열림.
- **PDF 저장·이미지 저장은 인쇄 대화상자를 거치지 않고 파일을 직접 만듭니다**(PDF는 A4 한 쪽 JPEG 내장, 이미지는 PNG 2~3배 해상도). 만든 뒤 시트에서 `저장`(다운로드 폴더) · `새 창에서 열기` · `공유해서 저장`(휴대폰 공유 시트) 중에 고를 수 있고, 앱 안 브라우저처럼 다운로드가 막히는 곳에서는 그 사실을 시트에 적어 알려 줍니다. `인쇄`는 브라우저 인쇄 창을 그대로 엽니다.
- **목사 안수증 지면**(한글 1쪽 + 영문 1쪽, `assets/ord.css`·`.od-*`): 금색 테두리 양식.
  - 교단 엠블럼 워터마크 — 지면 폭 **45%**, 진하기 **8%**(`wmTone`). 사진 자리 아래·지면 가운데.
  - 사진 모서리 교단 압인 — `assets/seals/stamp-emblem-*.png`. **원형 테두리 없이 교단 마크만** 눌린 모양이며(`.build/mk_stamp2.py` 가 로고의 원선 세 겹을 지우고 540/600 크기로 뜬다), 사진이 있을 때만 찍힌다. 화면·PDF·이미지 저장에는 들어가고 **브라우저 인쇄에서는 빠진다**.
  - 직인 — 노회장 인·서기 인이 각 **이름 위에 겹쳐** 찍히고, 노회 사각 인은 서명부 왼쪽에 온다. 영문 지면은 서명부가 한글판보다 위·오른쪽에 있어 `ord.css` 의 `[data-lang="en"]` 규칙이 차이(오른쪽 8.5mm·위 3.1mm)만 더한다. 관리자 값은 한글판 기준 mm 이다.
  - **한글 → 영문 자동 표기**(`assets/roman.js`) — 한글 성명·안수위원 명단을 넣으면 영문 칸이 저절로 채워진다(성은 관용 표기 표, 이름은 음절 분해 + 개정 로마자, `현 hyun`·`우 woo` 등 관용 표기 몇 개). 직접 고치면 자동이 멈추고 `자동으로` 단추로 되돌린다. 인터넷 없이 브라우저 안에서만 계산한다.

## 폴더
```
index.html            화면 + A4 지면
assets/app.css        화면·지면·인쇄 스타일 (지면은 mm 단위)
assets/app.js         동작 (정의를 읽어 폼과 지면을 그림)
data/types.json       증명서 종류별 정의 — 제목·항목·본문·추가 입력·워터마크
data/people.json      사람 명단 (교회명·이름·생년월일·주소·직위)
data/config.json      직인 기본 경로(seal) — 보통은 앱에서 직접 올리는 방식을 씁니다
assets/fonts/         지면 글꼴 — 나눔명조 부분집합(Regular·Bold, woff2) + OFL.txt
assets/logo-sky.svg   백석 로고(벡터) — 하늘색 워터마크(38% 기준)
assets/logo-white.svg 같은 로고 흰색 — 머리글 남색 띠 위 표기
assets/logo-deep.svg  같은 로고 진한 하늘(#1B5E8C) — 밝은 띠 시안용
assets/roman.js       한글 이름 → 영문(로마자) 자동 표기 (오프라인)
assets/ord.css        목사 안수증 지면(한글·영문) 조판
assets/band.png       보안 패턴 띠(스캔에서 추출)
vendor/html2canvas.min.js  이미지(PNG) 저장용
sw.js, manifest.webmanifest, assets/icons/  설치·오프라인용
```

## 고치는 법
- **문구·항목**: `data/types.json`. 7종 본문은 공문체(`~함`·`~음`)로 끝맺고 한 줄 40자 안쪽입니다. `body` 의 `{church} {name} {birth} {address} {position} {presbytery}` 는 입력값으로 바뀝니다. 앱 화면의 `본문 문구 수정` 에서도 종류별로 고칠 수 있습니다(그 기기 브라우저에만 저장).
  - 목사 안수 증명서는 `extra` 의 `ordainDate`(안수일)를 필수로 받고, 명단의 사람에도 `ordainDate` 로 저장됩니다(개척일 `plantDate`·설립일 `foundDate` 와 같은 자리).
- **명단**: `data/people.json` 의 `people` 배열에 사람을 더하면 됩니다.
- **양식 글자**: `양식 관리` 탭에서 지면 머리글·문서번호 접두어·하단 안내문·종류별 제목/본문/항목 이름/서명부 직함·성명을 고칩니다. 고친 값은 이 기기 브라우저에 저장되고 `기본값 복원` 으로 되돌립니다.
  - 지면은 **3단 고정 조판**입니다. 위(머리글)는 지면 위에 붙어 아래로만 자라고, 아래(보안 띠·Internet No·진위 문구)는 바닥에 붙어 위로 쌓입니다. 가운데(번호·제목·항목·본문·날짜·서명부)만 늘고 줍니다. 본문이 길어져 날짜 줄을 침범하면 그 종만 줄 간격을 조금 줄여 A4 한 장을 지킵니다.
  - 머리글은 **남색→하늘 그라데이션 띠** 안에 백석 로고(흰색 벡터)와 `대한예수교장로회(백석)  서울강동노회`(흰 글씨 9mm)를 **한 덩어리로 묶어 지면 폭 가운데**에 놓습니다. 띠 아래에는 `(05048) 노회 주소` · `Tel` · `Fax`를 **한 줄로** 3.45mm 크기로 찍고, 그 아래 가는 하늘색 구분선을 둡니다. 그 한 줄이 폭을 넘으면 그 줄만 자동으로 줄어듭니다(`fitOneLine`). 총회 주소는 기본값이 비어 있어 찍히지 않고, 채우면 주소 위에 한 줄 더 생깁니다.
  - **서명부**는 기관명 줄 아래에 `노회장`·`서기`를 **각각 다른 줄**로 두고, 직함은 왼쪽 정렬이라 두 직함의 시작과 두 이름(`이용동`·`박재용`)의 첫 글자가 같은 세로선에 섭니다. 기관명→첫 줄, 줄 사이, 직함↔이름 사이를 모두 **6mm 한 값**(`--sg-gap`)으로 맞췄습니다.
  - **직인 겹침**: 노회 사각 인은 기관명 끝 `노회` 글자 위에, 노회장·서기 원형 인은 각 이름 끝 글자 위에 반투명(사각 60%·원형 55%)으로 겹쳐 찍힙니다. 관리자 `서명부 · 직인` 에서 `1안(글자 위)`·`2안(어깨에 걸치게)`를 고를 수 있고, 2안은 원형 인을 이름 오른쪽 어깨에 살짝 걸쳐 이름 판독을 우선합니다(반투명 85%).
- **직인**: 기본 직인은 `assets/seals/` 의 세 장(노회장 인·서기 인·노회 사각 인)이고, 관리자나 `발급하기 → 직인` 에서 `넣기` 로 다른 사진을 올리면 그 기기에서 그것으로 바뀝니다. 올린 사진은 **그 기기 브라우저(localStorage)에만** 저장됩니다. `지우기` 를 누르면 기본 직인으로 돌아갑니다.
  - ⚠️ **기본 직인 파일은 공개 저장소에 들어 있어 누구나 URL로 내려받을 수 있습니다**(GitHub Pages·raw 주소 모두 확인). 실제 인감이므로 공개되면 안 되는 경우 `assets/seals/` 파일을 비공개 위치로 옮기고 관리자에서 기기별로 넣는 방식으로 바꿔야 합니다.
- **증명사진**: 관리자 → 사람 명단 → `사진 넣기`. 사진은 **그 기기 브라우저(localStorage)에만** 저장되고 저장소에 올라가지 않습니다.
- **워터마크**: 하늘색 로고(`assets/logo-sky.svg`, 벡터)를 진하기만 바꿔 씁니다. 기본 **38%**, 관리자에서 하늘 45% / 하늘 38% / 하늘 30% / 없음 중 고릅니다.
- **지면 글꼴**: `assets/fonts/` 의 나눔명조 부분집합을 씁니다(KS X 1001 한글 2,350자 + 앱에서 쓰는 글자, OFL 라이선스). 웹폰트를 저장소에 넣어 두어 기기·오프라인에서도 같은 지면이 나옵니다. 글자를 바꾸려면 `assets/app.css` 맨 위 `@font-face` 와 `.paper` 의 `font-family` 를 보세요.

## 주의
- 이 앱은 목사님이 발급 주체(노회 서기)로서 쓰는 실무 도구입니다. 하단 안내문의 Internet No.는 앱이 만든 자체 참조번호이며 총회 조회 시스템과 연동되지 않습니다.
